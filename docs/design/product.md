# 官网产品规格（规划）

## 一句话

让访客在一分钟内明白「花哪了」是本机时间追踪桌面应用，并知道如何下载。

## 受众

- 主要：需要看清自己时间花在哪的个人用户（Windows 与 macOS 桌面）
- 次要：关心隐私、不愿默认上云的用户

## 语言

- **中英双语**为 MVP 要求（不是后置）。
- 导航提供 `中 / EN` 切换；同一时刻只展示一种语言，不在同一行叠中英双语文案。
- 默认语言：可按浏览器 `Accept-Language` 猜测，并允许手动切换（实现时再定持久化方式）。

## 视觉方向（规划）

- 参考气质：[omlx.ai](https://omlx.ai/) — 白底、大留白、居中首屏、无衬线重字重、黑主按钮、下方产品窗预览；其下再跟介绍区块（非只有首屏）。
- 导航品牌：**应用 icon**（`public/app-icon.png`，源自 `huanale` `src-tauri/icons`）+ 文案「花哪了」。
- 品牌字体：**当前选用 D · 站酷小薇（ZCOOL XiaoWei）**；若观感不佳再换 A · Noto Sans SC Black。候选页：[brand-mark-font-samples.html](./brand-mark-font-samples.html)。
- 产品预览：**用真实应用截图**（`public/screenshots/timeline.png`），不用假 UI 拼图。时间轴形态以桌面端为准（竖直轴 + 泳道），见 `huanale` 仓 `docs/modules/timeline.md`。
- 不做：书法/毛笔品牌字、雾山插画底、仪表盘式功能墙、假甘特时间线。

## 信息架构（MVP，对齐 omlx 式长落地页）

1. **首屏**：价值主张 + 下载 CTA + 真实应用截图  
2. **为什么 / 能力**：时间线、规则报表、可选 AI 日报（各一小段，可配截图或一句说明）  
3. **隐私与边界**：本机默认、采/不采什么（信任向；不是法律长文）  
4. **FAQ**（短）：安装门槛、是否要账号、数据是否上传等  
5. **再下载 / 开始用**：页底重复 CTA  
6. **页脚**：GitHub / Releases、隐私、中英切换  

说明：omlx 的 Community Benchmarks / 跑分「reference」我们没有对等公开数据；不编造指标。若以后有可引用的事实（开源协议、平台要求、Release 版本），用页脚或 meta 行呈现即可。
## 与桌面产品的边界

- 官网不替代安装后的应用内体验
- 不承诺浏览器扩展、完整 URL、手机端等后期能力为「现已提供」，除非桌面仓已交付并对外宣布
