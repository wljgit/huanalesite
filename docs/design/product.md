# 官网产品规格（规划）

## 一句话

让访客在一分钟内明白「花哪了」是本机时间追踪桌面应用，并知道如何下载。

## 受众

- 主要：需要看清自己时间花在哪的个人用户（Windows 优先，macOS 随后）
- 次要：关心隐私、不愿默认上云的用户

## 信息架构（MVP）

1. 首屏：品牌 + 价值主张 + 下载
2. 能力摘要：时间线 / 规则报表 / 可选 AI 日报（各一句，不堆功能表）
3. 隐私：本机、采集边界
4. 页脚：仓库/联系（可选）

## 与桌面产品的边界

- 官网不替代安装后的应用内体验
- 不承诺浏览器扩展、完整 URL、手机端等后期能力为「现已提供」，除非桌面仓已交付并对外宣布
