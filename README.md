# 花哪了官网（huanalesite）

桌面应用「花哪了」的**介绍站、公开 Issues 与安装包 Releases**（Public）。  
本 README 亦作为官网站外 **Documentation** 入口（页脚「文档」链到本仓）。  
桌面应用源码在私有仓 `huanale`，不对外链。

- **栈**：Astro 静态站 → Cloudflare Pages（待连接）
- **语言**：`/` 中文，`/en/` 英文
- **下载**：Windows / macOS → 本仓 GitHub Releases

## 本地

```bash
npm install
npm run dev
npm test
npm run build
```

新会话从 [CLAUDE.md](./CLAUDE.md) 与 [docs/overview.md](./docs/overview.md) 读起。
